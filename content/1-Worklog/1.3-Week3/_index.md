### Week 3 Objectives

- Understand AWS Compute Services.
- Learn how to deploy and manage Amazon EC2 instances.
- Explore storage solutions associated with Amazon EC2.
- Understand the Auto Scaling mechanism for optimizing performance and cost.
- Become familiar with supporting services such as Amazon EFS, Amazon FSx, Amazon Lightsail, and AWS Application Migration Service (AWS MGN).

### Week 3 Achievements

- Developed a solid understanding of the architecture and operating principles of **Amazon Elastic Compute Cloud (Amazon EC2)**.

- Learned how to select the appropriate **EC2 Instance Type** based on different workload requirements.

- Understood the purpose and usage of:
    - Amazon Machine Images (AMI)
    - Key Pairs
    - Snapshots and Backups

- Successfully practiced launching and managing Amazon EC2 instances using:
    - AWS Management Console
    - AWS CLI

- Understood the differences between the following storage options:
    - Amazon Elastic Block Store (Amazon EBS)
    - EC2 Instance Store

- Learned how to use **User Data** to automate server configuration during instance launch.

- Understood the **EC2 Instance Metadata** service and how applications can access instance-specific information.

- Gained a solid understanding of **Amazon EC2 Auto Scaling**, including how it automatically adjusts the number of EC2 instances based on application demand.

- Became familiar with the following AWS services:
    - Amazon Elastic File System (Amazon EFS)
    - Amazon FSx
    - Amazon Lightsail
    - AWS Application Migration Service (AWS MGN)

- Successfully completed hands-on labs involving Amazon EC2 deployment, Amazon EBS volume management, and basic Auto Scaling configuration.

- Acquired the skills to deploy and manage virtual servers on AWS, providing a strong foundation for learning storage and database services in the following weeks.
