# Build & Deploy Fav Web Portal on AWS

#### Overview

In this hands-on workshop series, you will step-by-step build and deploy the complete **Fav Web Portal** application (AI Face Recognition & Multimedia Portal) onto **Amazon Web Services (AWS)** cloud infrastructure.

The architecture combines AWS cloud services including **Amazon S3** (Static Web Hosting & Object Storage), **Amazon EC2** (Containerized FastAPI Backend), **Amazon RDS** (Relational Database), alongside modern security mechanisms (CORS, CSP, JWT Bearer Fallback).
